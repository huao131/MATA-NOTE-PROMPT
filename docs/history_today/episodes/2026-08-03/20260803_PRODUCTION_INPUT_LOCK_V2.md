## Approved Voice Script

出發那天，港口的人不知道，
這一次告別，將改變世界。

1492年8月3日，
哥倫布帶著三艘船，
從西班牙帕洛斯港緩緩啟航。

在那個沒有衛星、沒有引擎，
甚至沒有完整世界地圖的年代，
沒有人知道前方有什麼，
也沒有人確定，他們還能不能回來。

哥倫布相信，
只要一路向西，
就能找到通往亞洲的新航路。

但他不知道，
海洋的另一端，
是一個歐洲人尚未真正認識的世界。

這趟原本為了尋找亞洲而開始的航行，
讓長久分隔的兩個世界，
從此再也無法分開。

歷史有時不是從知道答案開始，
而是從一群不知道能不能回來的人，
升起船帆，駛向未知。

只是他們改變的，
不只自己的命運，
而是兩個世界的未來。
