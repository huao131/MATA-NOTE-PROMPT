# EP02｜B1_V2.0 STORY FUNCTION LOCK

**Status:** LOCKED  
**Confirmed by:** Mata老師  
**Version:** V2.0  

## Story Function

林沐晴坐在美容工作室裡，開始思考是否能把自己的美容專業與工作日常拍成影片，腦中逐漸浮現幾個尚未發布的內容構想。

## Core Narrative Task

主角第一次意識到：自己的專業與日常，也許可以透過影片被更多人看見。

## Emotional Progression

迷惘 → 思考 → 靈感萌芽。

## Visual Requirements

- 主角坐在日光美學館工作櫃檯前。
- 一手自然托著下巴，視線微微向上或看向前方。
- 表情專注、若有所思，尚未進入成功或興奮狀態。
- 桌面可有手機、筆記本、筆與工作電腦，但尚未實際自拍或剪輯。
- 周圍僅可出現少量、柔和、半透明的影片內容構想，例如美容工作日常、保養觀念、服務過程與美容師故事。
- 構想畫面代表尚未發布的靈感，不得呈現正式社群貼文或成果。

## Prohibited Elements

- 按讚數、留言數、觀看數、粉絲數。
- 成交通知、客戶回流成果。
- 已發布成功的社群介面。
- 大型科幻全息控制中心。
- AI重繪Logo、假品牌文字或亂碼。

## Continuity Locks

- Character Master：林沐晴。
- Scene Master：日光美學館。
- Prop Master：日光美學館正式道具配置。
- 畫幅：9:16直式。
- B1為思考與靈感萌芽階段；B2才進入實際行動。

## QC Decision Rule

觀眾必須一眼看懂：她正在想「要拍什麼」，而不是已經拍完、發布或成功。

## Post-generation Review Gate

每次生成B1_V2.0候選圖片後，必須停在QC Gate，向Mata老師提出四項確認：

1. 人物是否正確？
2. 場景是否正確？
3. 劇情功能是否正確？
4. 本張圖片判定為：重生／修改／通過／Approved？
