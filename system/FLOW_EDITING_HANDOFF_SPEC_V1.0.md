# Flow & Editing Handoff Spec V1.0

Flow is semi-automated unless a supported official API is available. The system generates segment packages, prompts, input frame lists, model recommendations and QC records.

CapCut/剪映 is semi-automated unless a supported official API is available. The system generates editing timeline, voiceover, SRT, BGM/SFX cues, transitions, exact asset placement and final QC checklist.
