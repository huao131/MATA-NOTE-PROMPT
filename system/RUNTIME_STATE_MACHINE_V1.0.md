# Runtime State Machine V1.0

## Legal transitions

NEW_EPISODE -> BRIEF_REVIEW -> CREATIVE_GATE -> STORY_DEVELOPMENT -> STORY_VISUAL_GATE -> KEYFRAME_READY -> KEYFRAME_GENERATING -> QC_WAITING

QC_WAITING + 確認 -> KEYFRAME_GENERATING
QC_WAITING + OK -> QC_WAITING
QC_WAITING + PASS -> ASSET_UPLOADING -> QC_WAITING
QC_WAITING + APPROVED -> NEXT_KEYFRAME -> KEYFRAME_READY
QC_WAITING + 3+4 -> ASSET_UPLOADING -> NEXT_KEYFRAME -> KEYFRAME_READY

KEYFRAME_READY repeats until all frames approved.
All frames approved -> KEYFRAME_LOCKED -> FLOW_PACKAGE_READY -> FLOW_GENERATION -> FLOW_QC -> PRODUCTION_LOCKED -> EDITING_PACKAGE_READY -> FINAL_QC -> FINAL_APPROVED -> EPISODE_CLOSED

Illegal transitions must fail without changing files.
